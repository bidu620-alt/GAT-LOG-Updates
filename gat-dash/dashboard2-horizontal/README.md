# RoadLife Dashboard Horizontal

Protótipo isolado do Dashboard2 dedicado exclusivamente ao layout horizontal.

Objetivo: acertar primeiro proporção, legibilidade, moldura, contraste e distribuição do painel horizontal sem qualquer regra de rotação ou CSS vertical.

Decisões atuais:
- sem modo vertical neste módulo;
- velocidade/dados principais sempre em branco sólido;
- verde escuro usado como acento, com glow reduzido;
- velocímetro ocupa a coluna central;
- imagem do caminhão foi removida da área dinâmica;
- área direita mantém a carga dinâmica;
- telemetria continua compatível com o payload já usado pelo TruckSim GPS.
