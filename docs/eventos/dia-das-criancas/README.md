# Evento Dia das Crianças 2026

Pasta reservada para o evento Dia das Crianças 2026.

- Início: 05/10/2026 00:00 (horário de Brasília)
- Encerramento: 13/10/2026 00:00 (horário de Brasília)
- Cargas do evento: serão definidas após análise do banner.
- Regra: somente cidades de origem e destino; sem distância mínima.
- Cargas concluídas devem ficar visualmente marcadas como concluídas/verde.

Coloque o banner/imagem do evento nesta pasta. O arquivo poderá ser analisado para definir as cidades e demais regras do evento.
