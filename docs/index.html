VISÃO DO PROJETO

O site é a janela pública do GAT LOG.

A Conta GAT identifica o motorista; o aplicativo reconhece o jogador dentro da sessão ETS2 e envia a telemetria vinculada. O site mostra somente a atividade pública. Senhas, tokens e IDs do computador não são exibidos.
